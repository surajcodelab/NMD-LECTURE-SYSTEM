# NMD PVT LTD — Client Preview

A static, frontend-only presentation of the NMD learning management system. It contains an illustrative interface and fictional sample information; it does not connect to the Django backend, a database, authentication, or private learning files.

## Publish with GitHub Pages

1. Create a **public** GitHub repository named `NMD-LECTURE-SYSTEM`.
2. Push the files in this repository.
3. In GitHub, open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and the `/(root)` folder, then save.
5. After the Pages deployment completes, visit `https://surajcodelab.github.io/NMD-LECTURE-SYSTEM/`.

Only publish client-approved public content here. Do not add the Django source, credentials, database exports, student information, or private media.
